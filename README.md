# Earn&Learn 🎓
---

##  O aplikaciji

**Earn&Learn** je platforma namijenjena olakšavanju procesa učenja za studente ETF-a. Glavni ciljevi aplikacije su:
* **Povezivanje studenata:** Omogućava studentima koji imaju poteškoće s određenim gradivom da brzo pronađu adekvatnog tutora među svojim kolegama.
* **Zarada kroz znanje:** Pruža priliku studentima s odličnim poznavanjem određenih oblasti da pruže podršku drugima i ostvare zaradu.
* **Fleksibilnost:** Jednostavan pregled dostupnih termina, predmeta i ocjena tutora radi lakšeg odabira idealnog mentora.
